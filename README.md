# GPT-AI Chat Web

An intelligent web-based chatbot interface powered by OpenAI's GPT model. This project uses **ReactJS** and **TailwindCSS** for the frontend, and **Node.js + Express** for the backend. The app allows users to interact with an AI assistant in real-time, simulating a ChatGPT-like experience.

## Features

- ChatGPT-style conversational UI
- Fast and responsive design (mobile friendly)
- React frontend with Tailwind CSS
- Node.js + Express backend
- OpenAI GPT-3.5-turbo integration
- Secure API key usage via `.env`
- Easy to deploy (both frontend and backend)
